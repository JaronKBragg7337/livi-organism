# LIVI follow-up hardening

LIVI 0.5.0 ships the complete continuity release. These are intentionally
deferred hardening and research tasks, not missing release features:

1. Run destructive multi-device sync chaos tests against disposable accounts:
   offline edits, concurrent purchases, key recovery, key rotation, revision
   restore, and three-way conflicts.
2. Stress multi-year local memory with browser quota failures and IndexedDB
   interruption/recovery. Confirm that the localStorage head can be missing or
   corrupt without losing the IndexedDB organism.
3. Repeat the full care, camera, account, recovery, and conflict flows on
   physical iPhones in Safari and Android phones in Chrome, including
   background suspension and low-memory tab eviction.
4. Expand inherited memories into more observable behavior: conditioned
   responses to rooms, toys, friend signals, revival cues, and care-time
   anticipation.
5. Add production error reporting and synthetic monitoring without collecting
   camera frames, precise location, room imagery, or private decrypted saves.
6. Keep dependency review current. The 0.5.0 production dependency audit is
   clean; remaining development-tool advisories should be reassessed as the
   Vinext toolchain advances.

Do not replace the immutable revision or memory ledgers with a mutable “current
save” table. Preserve account-free play, client-side encryption, CC0 licensing,
earned-Mote-only economy, and the rule that meaningful appearance and behavior
must arise from organism state.
